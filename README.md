## 轻量应用服务器还是云服务器 ECS？

个人网站、博客、外贸展示站、开发测试、学习用途，选轻量；需要弹性伸缩、自定义网络架构、高并发或数据库密集型的业务，选 ECS。两者没有绝对优劣，定位本来就不一样：轻量是简化版，套餐化、含大流量包、容易上手，但性能上限低；ECS 是专业版，配置灵活、可对接阿里云完整生态，但更复杂，流量还要单独计费。

轻量为简化体验设了几条硬限制，下单前知道有备无患：

- 公网 IP 默认不支持更换，服务器到期后 IP 不会保留
- 中国内地地域默认禁止 25 端口出方向（发邮件）和 53 端口入方向（DNS），要发邮件请走 SSL 加密的 465 端口
- 套餐带宽是峰值上限，网络资源紧张时可能被限制，对时延和稳定性有强保障要求的业务不适合
- 系统盘采用本地高性能磁盘，没有云盘那样的数据自动冗余，重要数据记得定期做快照

业务做大了也不用推倒重来，官方提供从轻量迁移到 ECS 的工具。顺带一提，同一个活动页里 ECS 也有 99 元/年、续费同价的活动机型，两边预算接近时可以比一比。

## 常见问题

### 阿里云轻量应用服务器需要备案吗？

只有中国大陆地域需要。香港和 12 个海外节点全部免备案，购买后绑定域名即可对外访问。

### 200M 峰值带宽是不限流量吗？

是。200M 指限峰值带宽，官方明确不限流量，但它并非承诺带宽——业务高峰资源紧张时可能被限制。跑网站、部署应用没问题；要求带宽随时随地稳定不抖，应该去看 ECS 的固定带宽方案。

### 68 元/年的套餐续费会涨价吗？
